# Assets Publicos

Arquivos desta pasta sao servidos pelo GitHub Pages.

## Conteudo

- `logo.png`: logo usada no site e no chat.
- `logo.ico`: favicon do site.
- `meu-site-downloads/`: arquivos que aparecem na secao de downloads do site.

## Cuidado

Nao renomear arquivos de download sem atualizar os links no `index.html` ou no `script.js`.
